ERGOGAMESHOW — วิธีติดตั้งแบบทีละขั้น
======================================

ไฟล์ในชุดนี้
------------
1) index.html
   หน้าเว็บหลักสำหรับ GitHub Pages

2) Code.gs
   วางใน Google Apps Script ที่ผูกกับ Google Sheet

3) assets/
   โฟลเดอร์สำหรับใส่ภาพคำถาม

--------------------------------------------------
A) เตรียมรูปภาพ
--------------------------------------------------

ให้สร้าง/ใส่ไฟล์รูปด้วยชื่อ EXACTLY ตามนี้:

assets/q4_1.jpg   = ข้อ 4 ภาพที่ 1 (คำตอบที่ถูกตาม key ปัจจุบัน)
assets/q4_2.jpg   = ข้อ 4 ภาพที่ 2

assets/q7.jpg     = รูปท่าออกกำลังกายสำหรับข้อ 7

assets/q8_1.jpg   = ข้อ 8 ภาพที่ 1 (คำตอบที่ถูกตาม key ปัจจุบัน)
assets/q8_2.jpg   = ข้อ 8 ภาพที่ 2
assets/q8_3.jpg   = ข้อ 8 ภาพที่ 3

คำแนะนำ:
- ใช้ JPG หรือ PNG ก็ได้ แต่ถ้าใช้ PNG ต้องแก้ .jpg ใน index.html ให้ตรง
- แนะนำภาพกว้างประมาณ 1000–1600 px
- ขนาดไฟล์ต่อรูปประมาณ 100–500 KB จะโหลดได้เร็วบนมือถือ
- หลีกเลี่ยงชื่อไฟล์ภาษาไทย/เว้นวรรค เพื่อป้องกัน path error
- ถ้ายังไม่ใส่ภาพ หน้าเว็บจะแสดง placeholder แทน

--------------------------------------------------
B) เตรียม Google Sheet
--------------------------------------------------

1. สร้าง Google Sheet ใหม่
2. ไปที่ Extensions > Apps Script
3. ลบโค้ดเดิม แล้ววาง Code.gs จากชุดนี้
4. กด Save
5. เลือกฟังก์ชัน setupSheet
6. กด Run
7. อนุญาตสิทธิ์ครั้งแรก
8. กลับไปดู Sheet จะมีแท็บชื่อ "ErgoGameshow"
   และมี header เตรียมไว้แล้ว

--------------------------------------------------
C) Deploy Google Apps Script เป็น Web App
--------------------------------------------------

1. ใน Apps Script กด Deploy > New deployment
2. Select type > Web app
3. Description: ErgoGameshow API
4. Execute as: Me
5. Who has access:
   - เลือก "Anyone" หากบัญชีอนุญาต
   - ถ้าเป็นบัญชีองค์กรและไม่มี "Anyone"
     ให้เลือกตัวเลือกที่องค์กรอนุญาต และทดสอบตามนโยบาย IT
6. กด Deploy
7. Copy URL ที่ลงท้ายด้วย /exec

ตัวอย่าง:
https://script.google.com/macros/s/XXXXXXXXXXXX/exec

--------------------------------------------------
D) ใส่ Web App URL ใน index.html
--------------------------------------------------

ค้นหาบรรทัดนี้ใน index.html:

const WEB_APP_URL = "PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";

แล้วเปลี่ยนเป็น:

const WEB_APP_URL = "https://script.google.com/macros/s/XXXXXXXXXXXX/exec";

Save ไฟล์

--------------------------------------------------
E) อัปขึ้น GitHub Pages
--------------------------------------------------

โครงสร้างควรเป็น:

your-repository/
├─ index.html
└─ assets/
   ├─ q4_1.jpg
   ├─ q4_2.jpg
   ├─ q7.jpg
   ├─ q8_1.jpg
   ├─ q8_2.jpg
   └─ q8_3.jpg

1. สร้าง repository
2. Upload index.html
3. Upload โฟลเดอร์ assets พร้อมรูป
4. ไป Settings > Pages
5. Source: Deploy from a branch
6. Branch: main / root
7. Save
8. เปิด URL ของ GitHub Pages

--------------------------------------------------
F) สิ่งที่ระบบบันทึกใน Google Sheet
--------------------------------------------------

- เวลา submit
- รหัสผู้เข้าร่วม
- ชื่อ/ชื่อเล่น
- หน่วยงาน
- เลือกปวดหลังล่างหรือไม่ + score 0–10
- เลือกปวดหัวไหล่หรือไม่ + score 0–10
- เลือกปวดหัวเข่าหรือไม่ + score 0–10
- คำตอบข้อ 1–10
- ถูก/ผิดแต่ละข้อ
- คะแนนรวม /10
- เปอร์เซ็นต์
- URL หน้าเว็บ
- browser user-agent

--------------------------------------------------
G) ถ้าจะเปลี่ยนเฉลย
--------------------------------------------------

ใน index.html ค้นหา:

const ANSWER_KEY = {
  q1: "D",
  q2: "C",
  q3: "A",
  q4: "A",
  q5: "D",
  q6: "A",
  q7: "A",
  q8: "A",
  q9: "D",
  q10: "A"
};

A = ก
B = ข
C = ค
D = ง

เช่น ถ้าข้อ 4 เปลี่ยนให้ภาพที่ 2 ถูก:
q4: "B"

--------------------------------------------------
H) การทดสอบก่อนใช้งานจริง
--------------------------------------------------

1. เปิด GitHub Pages บนคอม
2. ลองกรอก EMP001
3. ตอบคำถามครบ 10 ข้อ
4. กดส่ง
5. ต้องเห็นคะแนนบนหน้าเว็บ
6. เปิด Google Sheet
7. ตรวจว่ามีข้อมูลเพิ่ม 1 row
8. ทดลองบนมือถืออีกครั้ง

หมายเหตุสำคัญ:
หน้าเว็บใช้ fetch(..., mode: "no-cors") เพื่อให้ใช้ง่ายกับ GitHub Pages
ดังนั้นหน้าเว็บจะทราบว่า "ส่ง request ออกไปแล้ว" แต่ไม่สามารถอ่านข้อความตอบกลับจาก Apps Script ได้โดยตรง
หากต้องการยืนยันว่าบันทึกจริง ให้ตรวจใน Google Sheet ตอนทดสอบครั้งแรก
